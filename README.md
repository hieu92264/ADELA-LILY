# Adela Clone

Static HTML landing page scaffold using Tailwind CSS 4 and Vite.

## Structure

- `src/index.html` - main landing page sections.
- `src/parts/header.html` - reusable site header.
- `src/parts/footer.html` - reusable site footer.
- `src/css/input.css` - Tailwind entry file and small shared component classes.
- `src/js/main.js` - partial injection and mobile navigation.
- `public/assets/images` - local images and static assets.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

Development URL defaults to `http://localhost:5173`.
